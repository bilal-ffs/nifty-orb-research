# NIFTY 50 Opening Range Breakout Research

A reproducible study of opening-range breakouts, execution assumptions,
transaction costs, and chronological logistic-regression validation.

**Main finding:** the baseline loses money after the modeled costs in both
historical periods. The classifiers do not demonstrate a consistent overall
probability-forecast advantage or a profitable trading filter. Negative findings
are retained alongside the code and assumptions that produced them.

## Recorded baseline results

These are saved historical results, not newly generated by publication packaging.
Each period starts independently with INR 1,000,000 and fixed INR 100,000
notional per trade. Prices are a spot-index proxy, not executable futures quotes.

| Metric | Development: 2015-2021 | Historical test: 2022-Jul 2025 |
| --- | ---: | ---: |
| Completed trades | 1,624 | 852 |
| Gross P&L, INR | 32,139.10 | 16,824.13 |
| Net P&L, INR | -162,720.79 | -85,416.72 |
| Net profit factor | 0.630 | 0.590 |
| Mean net R/trade | -0.283 | -0.298 |
| Daily account Sharpe, 252 sessions, rf=0 | -2.705 | -3.540 |
| Closing-account maximum drawdown | 16.94% | 8.66% |

Fees are 5 bps per side and adverse slippage is 1 bp per fill. Gross and net
share the realized execution path; gross is not a separate zero-slippage run.
R divides points by actual entry-to-stop risk and is not an account return.
See the [full baseline report](orb_research_report.md) and saved
[development](orb_is_metrics.json) / [test](orb_oos_metrics.json) metrics.

## Experiments and authoritative reports

| Experiment | Question and scope | Result / report |
| --- | --- | --- |
| Baseline ORB | Does the first one-minute breakout of the opening range survive costs? Separate 2015-2021 and 2022-2025 runs. | Negative net expectancy in both periods. [Report](orb_research_report.md). |
| IS diagnostics | Where do costs, direction and feature-conditioned outcomes differ? | Descriptive, not selected trading filters. [Report](orb_diagnostics_is.md). |
| Pooled logistic V1 | Can signal-time features predict the 1.5R target exit? Five expanding IS folds. | OOF ROC-AUC 0.554; log loss 0.577 versus baseline 0.564. [Report](orb_logistic_v1/report.md). |
| Directional logistic V2 | Do separate long/short models improve matched-event forecasts? IS only. | No consistent overall forecast or positive net-R ranking advantage. [Report](orb_logistic_directional_v2/comparison_report.md). |
| Cost-adjusted Vervoort ATR | Ten ATR multipliers, close versus next-open execution; IS only. | All ten primary next-open configurations have negative net expectancy. [Report](orb_vervoort_atr_research/research_report.md). |
| Legacy translation | Does a five-minute translation reconcile with a TradingView export and minute execution? Full-history exploration. | Before-cost results; incomplete export parity. [Report](legacy_translation/PY_ORB_RESULTS.md). |

The experiments have different rules, targets, entry windows and execution
models. Their P&L must not be pooled or interpreted as one sequentially validated
strategy. Legacy full-history exploration overlaps the baseline test period;
the repository as a whole has **no fresh untouched holdout**. IS-only model
experiments do not establish OOS generalization. See
[research and validation boundaries](docs/METHODOLOGY.md).

## Quick start: no market data required

Python 3.11-3.13 is the intended supported range. From the repository root:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements-research.txt
python scripts/run_tests.py
python scripts/check_publication.py
```

On Linux/macOS activate with `source .venv/bin/activate`. GitHub Actions runs the
same synthetic suites on Python 3.11, 3.12 and 3.13. Synthetic tests exercise the
actual execution/model functions using invented fixtures: next-open timing,
stop-first collisions, gaps, cost reconciliation, causal features, ATR/trailing
stops, expanding validation, label-maturity purging and fold-only preprocessing.
Private-data artifact suites are not selected by default. Passing synthetic
tests is not verification of historical performance. See
[validation record](docs/VALIDATION.md). Local preparation also passed all 69
tests with private historical artifacts in a disposable copy; those inputs are
not included here.

## Reproduce historical research

Raw minute data, row-level feature/trade exports and serialized models are
excluded. Their source redistribution rights have not been established. Obtain
an authorized input independently; no data downloader is bundled.

The baseline supports a source and output path:

```powershell
python orb_pipeline.py --source "D:/private/NIFTY_50_minute.csv" --output results/baseline
```

A different input will produce different results. Rebuilding the historical ML
studies requires the matching baseline outputs and private artifacts. See the
[complete reproduction guide](docs/REPRODUCING.md) for schema, source hashes,
commands, output locations and optional historical reconciliation tests.

## Repository layout

- `orb_pipeline.py`, `tests/`: baseline engine and portable synthetic tests.
- `orb_diagnostics.py`: development-only cost and feature diagnostics.
- `orb_logistic_v1/`, `orb_logistic_directional_v2/`: fixed chronological models.
- `orb_vervoort_atr_research/`: distinct cost-adjusted five-minute experiment.
- `legacy_translation/`: separately labeled before-cost exploration.
- `docs/`: methodology, data provenance, reproduction and validation.
- `scripts/`: isolated test runner and publication-content checks.

Research code and aggregate reports are kept together; large generated inputs,
trade-level outputs, models and caches are ignored. Publication packaging did not
change signal rules, cost assumptions, historical metrics, or original datasets.
Original source hashes are recorded in [original_sources.json](docs/original_sources.json).

## Limitations and licensing

Full-session completeness is a retrospective sample screen, not a live morning
filter. There is no independently certified full exchange calendar. Historical
index fills omit futures basis, rolls, margin, contract lots and real latency;
modeled fees are illustrative. Bootstrap/feature summaries and multiplier
comparisons are descriptive and not adjusted for all research selection.
